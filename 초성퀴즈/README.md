# 초성 퀴즈 🧩

초성만 보고 단어를 맞히는 한국어 퀴즈 게임입니다.

## 플레이 방법

1. 화면에 표시된 초성을 보고 해당하는 단어를 입력하세요
2. **확인** 버튼 또는 Enter 키로 정답을 제출합니다
3. 모르겠으면 **힌트** 버튼을 사용할 수 있어요 (힌트 사용 시 5점)
4. **건너뛰기**로 다음 문제로 넘어갈 수 있어요
5. 10문제가 끝나면 최종 점수를 확인하세요

## 점수 계산

| 상황 | 점수 |
|------|------|
| 힌트 없이 정답 | +10점 |
| 힌트 사용 후 정답 | +5점 |

## 카테고리

음식 · 동물 · 나라 · 직업 · 스포츠 · 자연

## 실행 방법

별도 설치 없이 `index.html` 파일을 브라우저에서 열면 바로 플레이할 수 있습니다.
